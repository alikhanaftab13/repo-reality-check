# CLAUDE.md

## Open-source tool questions
For tasks involving local/self-hosted LLMs, image or video generation, model fine-tuning or steering, terminal or personal AI agents, scraping, video downloading, network scanning, packet analysis, OSINT, or face swap, use the `oss-tool-picker` skill (`.claude/skills/oss-tool-picker/SKILL.md`). It maps tasks to 13 vetted repos and carries the safety rules (authorized targets only, consent for face swap, sandbox agents, read installers before running). No path needs to be supplied by the user.
